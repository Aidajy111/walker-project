# Walker: Сервис планирования маршрутов по Байкальскому региону

Walker — это веб-приложение, предназначенное для популяризации туризма в Бурятии и Иркутской области через предоставление готовых экспертных маршрутов с возможностью их персональной адаптации.

## Описание проекта

Проект решает проблему сложности планирования самостоятельных путешествий. Вместо поиска разрозненной информации, пользователь получает доступ к верифицированным маршрутам, которые включают в себя точки интереса (POI), заведения-партнеры и логистические рекомендации.

### Основные возможности
* Просмотр каталога маршрутов от администраторов и тур-агентов.
* Фильтрация по регионам, бюджету, сезону и тегам.
* Сохранение выбранных маршрутов в личную коллекцию.
* Инструментарий для редактирования копии маршрута «под себя» (изменение порядка точек, удаление ненужных локаций).
* Интерактивная карта с визуализацией трека и ключевых остановок.
* Система монетизации через выделение партнерских заведений (кафе, отели, музеи) внутри маршрута.

## Технологический стек

Проект разработан с учетом требований к масштабируемости и доступности поддержки в долгосрочной перспективе.

* **Frontend:** React.js (обеспечивает высокую интерактивность карт и списков).
* **Backend:** Node.js + Express.js (оптимальное решение для быстрого развертывания и простоты поддержки).
* **База данных:** PostgreSQL (хранение связей между маршрутами, пользователями и точками).
* **Управление контентом:** Strapi Headless CMS (административная панель для управления справочниками и контентом маршрутов).

## Структура данных маршрута

Каждый маршрут в системе содержит:
1. Заголовок и текстовое описание.
2. Медиа-галерею (обложка и фотографии локаций).
3. Систему тегов (например: #активныйотдых, #зима, #гастротур).
4. Список точек интереса с метаданными (адрес, описание, тип транспорта).
5. Бюджетную категорию и рекомендуемый сезон.

## Установка и запуск

### Требования
* Node.js (версия 18 и выше)
* PostgreSQL
* Установленная и настроенная Strapi CMS

### Инструкция
1. Склонируйте репозиторий:
   git clone https://github.com/Aidajy111/Walker.git

2. Установите зависимости для бэкенда и фронтенда:
   npm install

3. Настройте файл .env согласно примеру .env.example (укажите параметры подключения к БД и API ключи карт).

4. Запустите проект в режиме разработки:
   npm run dev
